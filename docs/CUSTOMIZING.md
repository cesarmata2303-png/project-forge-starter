# Customizing Forge Starter

- Change colors and spacing in `src/app/globals.css`.
- Edit the default exercise and workout-template seeds in `src/lib/storage.ts`.
- Add local-only pages under `src/app/(main)` and link them from the navigation components.
- Keep personal secrets out of source control. Starter requires no environment variables.
